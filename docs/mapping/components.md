# Components Object

Rules for the [Components Object](https://spec.openapis.org/oas/v3.0.3#components-object).

Tests are in `src/test/java/be/timvw/openapi/rust/`; a test is named `Class#method`.

### `components.schemas`

| | |
| --- | --- |
| OpenAPI | a schema under `components.schemas` that renders a type (an object, enum or union; a scalar has no type of its own) |
| Rust | a type named in `CamelCase` in a `snake_case` file of `src/models` (`ChatCompletion` in `chat_completion.rs`), re-exported as `models::ChatCompletion`. Hyphens are removed (`Thing-2` is `Thing2`). Two components with one Rust name fail generation |
| Options | stock `--model-name-prefix`, `--model-name-suffix` and `--model-name-mappings` name the type and keep the file of the schema: `Pet` with prefix `Api` is `ApiPet` in `api_pet.rs`, with suffix `Dto` `PetDto` in `pet_dto.rs`, and mapped to `Animal` it is `Animal` in `pet.rs`. Union variants and the string enum branches a union hoists into a model ([`schema.oneOf.variant-names`](schema.md#schemaoneofvariant-names)) get the prefix and suffix once, on the type (`Circle(models::ApiCircle)` and `TextVariant(models::ApiLooseTextVariantEnum)`, not `ApiCircle(models::ApiCircle)` and `ApiApiTextVariant(models::ApiApiLooseApiTextVariantEnum)`). Stock `--schema-mappings Filter=crate::custom::Filter` uses a type of your own in place of the schema, as the Java generators do: every reference (a field, an array item, a map value, a union variant, a parameter, a request body, a response) is the mapped path as given, without `models::`, and no model, doc or `models::` re-export is written for the schema. The schema mapping wins over a prefix, suffix or name mapping of that schema; a union variant keeps the schema's name (`Filter(crate::custom::Filter)`). The type needs what the generated types around it derive (`Clone`, `Debug`, `PartialEq`, `Serialize`, `Deserialize`). A parameter of it is sent as a generated type of the schema's shape would be: in place of an object schema (properties, `additionalProperties` or `allOf`) as its JSON, as a struct is ([`schema.properties.display`](schema.md#schemapropertiesdisplay)); in place of any other schema with `Display`, which the type then needs. A union picks the variant by the schema's shape (an object for an object schema), with the tag value a discriminator gives it. Stock `-g rust` names `models::Filter` everywhere and writes no `models::Filter`, so the crate does not compile. `--type-mappings` maps OpenAPI types (`string`, `DateTime`, ...), not schema names, and `--import-mappings` does nothing (Rust has no imports to add) |

### `components.schemas.docs`

| | |
| --- | --- |
| OpenAPI | the types of the models' properties, of the parameters and of the return types, in the generated Markdown (`docs/<Model>.md`, `docs/<Tag>Api.md`) |
| Rust | the Markdown shows the Rust type, linked to the doc of the one model it names (`Vec<models::Pet>` and `HashMap<String, Vec<models::Kind>>` to `Pet.md` and `Kind.md`). A type that names no model of the crate (`String`, `Vec<String>`, `uuid::Uuid`, `std::path::PathBuf`, `serde_json::Value`, an inline enum, a type a schema mapping names) is shown without a link. Stock linked the container (`Vec.md`), the primitive (`String.md`), a library path (`std::path::PathBuf.md`), the schema name of an inline response (`createPet_200_response.md`) or a model that is not written (`AnyOf.md`), files that do not exist |
| Options | always |
